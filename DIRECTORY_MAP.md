# Directory Map: All Window Links
Start here: project root (the extension has no subfolders).

## Folders
- `./` - extension manifest, popup page and popup script

## Where to change things
- Change what is copied or the output format -> `./` (popup script)
- Change permissions, name or version -> `./` (manifest)
- Change the popup text or style -> `./` (popup page)

## Ignore when searching
- `.git/` - git data
